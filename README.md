## Features

- **Interactive visualizations** — epsilon-delta demos, Riemann sums, slope fields, 3D surfaces, all on Canvas 2D / WebGL
- **KaTeX math rendering** — rigorous notation throughout
- **Exercises with hints & solutions** — from computational drills to proofs
- **Progress tracking** — saved locally in your browser
- **Zero dependencies** — just open the link and learn
